# சொல் தடம் (Sol Thadam) — தமிழ் சூழல் சொல் பொருள் ஆய்வி

> **“சொற்களின் பொருளைச் சூழலுடன் அறிந்திடுவோம்!”**

**சொல் தடம் (Sol Thadam)** என்பது ஒரே தமிழ் சொல் பல்வேறு வாக்கியச் சூழல்களில் வேறுபடும் நுட்பமான பொருளை (Contextual Word Sense) இனங்கண்டு விளக்கும் முழுமையான தமிழ்க் கல்வி இணையதளமாகும் (Tamil Word Sense Disambiguation Explorer).

---

## திட்டத்தின் நோக்கம் (Project Objective)

தமிழில் பல சொற்கள் ஒரே எழுத்து வடிவத்தைக் கொண்டிருந்தாலும், அவை இடம்பெறும் வாக்கியத்தின் சூழலைப் பொறுத்து மாறுபட்ட பொருள்களைத் தருகின்றன:

* **எடுத்துக்காட்டு 1 (படி):**
  * *வாக்கியம்:* நன்றாகப் படி. $\rightarrow$ **படித்தல்** (Learn / Study)
  * *வாக்கியம்:* அவன் படியில் ஏறினான். $\rightarrow$ **படிக்கட்டு** (Step / Stair)
  * *வாக்கியம்:* அவள் சொன்னபடி செய்தேன். $\rightarrow$ **கூறிய விதத்தில்** (In the manner said)

* **எடுத்துக்காட்டு 2 (ஆறு):**
  * *வாக்கியம்:* ஆற்றில் தண்ணீர் ஓடுகிறது. $\rightarrow$ **நதி** (River)
  * *வாக்கியம்:* என்னிடம் ஆறு புத்தகங்கள் உள்ளன. $\rightarrow$ **ஆறு என்ற எண்** (Number 6)

* **எடுத்துக்காட்டு 3 (மாலை):**
  * *வாக்கியம்:* அவள் பூ மாலை அணிந்தாள். $\rightarrow$ **பூமாலை** (Flower garland)
  * *வாக்கியம்:* மாலை நேரத்தில் விளையாடினோம். $\rightarrow$ **மாலை நேரம்** (Evening time)

* **எடுத்துக்காட்டு 4 (பால்):**
  * *வாக்கியம்:* குழந்தை பசும்பால் குடித்தது. $\rightarrow$ **பால் என்ற உணவு** (Milk)
  * *வாக்கியம்:* நீதிபதி நடுநிலையோடு தீர்ப்பு கூறினார், எந்தப் பாலும் சாயவில்லை. $\rightarrow$ **ஒரு பக்கம் அல்லது சார்பு** (Side / Bias)

* **எடுத்துக்காட்டு 5 (அடி):**
  * *வாக்கியம்:* அவனுடைய பாதத்தின் அடியில் காயம் ஏற்பட்டது. $\rightarrow$ **பாதத்தின் கீழ்ப்பகுதி** (Sole of foot)
  * *வாக்கியம்:* அவன் பந்தை வேகமாக அடித்தான். $\rightarrow$ **அடித்தல்** (To strike / hit)
  * *வாக்கியம்:* இந்த அறையின் நீளம் பத்து அடி. $\rightarrow$ **அளவுக்கான அலகு** (Unit of length - Foot)

இத்தளம் வெறுமனே அகராதியின் முதல் பொருளைக் காட்டாமல், வாக்கியச் சூழலில் உள்ள துணைச் சொற்களையும் வடிவங்களையும் பகுப்பாய்வு செய்து உரிய பொருளை விளக்குகிறது.

## தொழில்நுட்பக் கட்டமைப்பு (Tech Stack)

### பயனர் இடைமுகம் (Frontend)
* **கட்டமைப்பு:** React 19, TypeScript, Vite
* **வடிவமைப்பு:** Tailwind CSS v4, Lucide தமிழ் அடையாளக் குறியீடுகள் (Icons)
* **எழுத்துரு:** நோட்டோ சான்ஸ் தமிழ் (Noto Sans Tamil), முக்தா மலர் (Mukta Malar)
* **வசதிகள்:** 100% தமிழ் பயனர் இடைமுகம், Web Speech API (பேசித் தேடுதல் & குரல் வாசிப்பு)

### பின்தளம் (Backend)
* **மொழி & கட்டமைப்பு:** Python 3.14 / 3.11+, FastAPI, Pydantic v2
* **பகுப்பாய்வுப் பொறி:** சூழல் குறிப்புகள் பொருத்தம் (Context Clues Overlap), தமிழ் ஒருங்குறிச் சீராக்கம் (Unicode NFC), வேற்றுமை உருபு வடிவம் அறிதல் (Morphological Affixes), வெளிப்படையான மொழியியல் மதிப்பீடு (Transparent Heuristic Scoring)
* **சோதனை:** Pytest

## நிறுவல் மற்றும் இயக்கும் வழிமுறைகள் (Installation & Setup)

விண்டோஸ் பவர்ஷெல் (Windows PowerShell) முனையத்தில் பின்வரும் கட்டளைகளை இயக்கவும்:

### 1. பின்தளத்தை நிறுவி இயக்குதல் (Backend Setup)

```powershell
# Sol Thadam அடைவிற்குச் செல்லவும்
cd "c:\Users\DELL\OneDrive\Desktop\Sol Thadam"

# பின்தள மெய்நிகர் சூழலை (Virtual Environment) உருவாக்குதல்
python -m venv backend\.venv

# மெய்நிகர் சூழலைச் செயல்படுத்துதல்
backend\.venv\Scripts\Activate.ps1

# பின்தளத் தொகுப்புகளை நிறுவுதல்
python -m pip install -r backend\requirements.txt

# பின்தள சேவையகத்தை இயக்குதல்
cd backend
python -m uvicorn app.main:app --reload --port 8000 --host 127.0.0.1
```

*பின்தளம் இப்போது **http://127.0.0.1:8000** என்ற முகவரியில் இயங்கும்.*
*FastAPI தானியங்கி ஆவணங்கள்: **http://127.0.0.1:8000/docs***

## API இறுதிப்புள்ளிகள் (API Endpoints)

* `GET /api/health` — சேவை நிலை மற்றும் தரவுத்தொகுப்பு விவரங்கள்
* `GET /api/words` — களஞ்சியத்தில் உள்ள சொற்களின் பட்டியல் (தேடல் மற்றும் வடிகட்டுதல் வசதியுடன்)
* `GET /api/words/{word}` — ஒரு குறிப்பிட்ட சொல்லின் அனைத்துப் பொருள்கள் மற்றும் சான்றுகள்
* `POST /api/analyze` — வாக்கியத்தையும் சொல்லையும் கொண்டு சூழல் பொருளைப் பகுப்பாய்வு செய்தல்
* `GET /api/quiz/questions` — சரிபார்க்கப்பட்ட பல பொருள் சொற்களிலிருந்து வினாடி வினா வினாக்கள்

## களஞ்சியத் தரவுத்தொகுப்பை மாற்றுதல் அல்லது விரிவுபடுத்துதல் (Extending Dataset)

தரவுகள் `backend/data/tamil_wsd_dataset.csv` கோப்பில் சேமிக்கப்பட்டுள்ளன (UTF-8 / UTF-8-SIG).

புதிய சொல் சேர்க்க விரும்பினால் பின்வரும் நெடுவரிசைகளை நிரப்பவும்:
1. `id` — வரிசை எண்
2. `target_word` — அடிப்படைத் தமிழ் சொல் (எ.கா. படி)
3. `target_form` — வாக்கியத்தில் தோன்றும் வடிவம் (எ.கா. படியில்)
4. `sense_label` — தனித்துவக் குறியீடு (எ.கா. PADI_STAIR)
5. `meaning_tamil` — தமிழ்ப் பொருள் (எ.கா. படிக்கட்டு)
6. `meaning_english` — ஆங்கிலப் பொருள் (எ.கா. Step or stair)
7. `explanation_tamil` — எளிய தமிழ்க் கல்வி விளக்கம்
8. `sentence` — மாதிரிச் சான்று வாக்கியம்
9. `context_clues` — அச்சூழலை உறுதிப்படுத்தும் துணைச் சொற்கள் (இடைவெளியிட்டு எழுதவும்)
10. `source` — தரவு மூலம்
11. `annotation_status` — சரிபார்க்கப்பட்டது
12. `image_alt_text` — படத்திற்கான மாற்று உரை
13. `image_prompt` — படக் குறிப்பு
14. `image_search_url` — விக்கிமீடியா தேடல் இணைப்பு
15. `image_status` — உள்ளது / இல்லை

## பொதுவான பிழைகளும் தீர்வுகளும் (Troubleshooting)

1. **துறை பயன்பாட்டில் உள்ளது (Port 8000 or 5173 already in use):**
   * பிழை: `[Errno 10048] only one usage of each socket address`
   * தீர்வு: பவர்ஷெல்லில் இயங்கும் முந்தைய செயல்முறையை மூடவும்:
     ```powershell
     Stop-Process -Name python, node -Force -ErrorAction SilentlyContinue
     ```

2. **குரல் உள்ளீடு செயல்படவில்லை (Microphone not working):**
   * குரல் உள்ளீடு Google Chrome அல்லது Microsoft Edge உலாவிகளில் Web Speech API ஆதரவுடன் சிறப்பாக இயங்குகிறது.
   * உலாவி ஒலிவாங்கி (Microphone) அனுமதியை வழங்கியுள்ளீர்களா என்பதை முகவரிப் பட்டையில் உள்ள பூட்டு (Lock) குறியீட்டை அழுத்திச் சரிபார்க்கவும்.

3. **தமிழ் குரல் ஒலிப்பில் சிக்கல் (Tamil Speech Synthesis):**
   * கணினியில் தமிழ் மொழிப் பொதி (Tamil Language Speech Pack) நிறுவப்படாத சூழலில் உலாவி இயல்பு குரலைப் பயன்படுத்தும்.

## தற்போதைய வரம்புகள் (Current Limitations)

1. தற்போது களஞ்சியத்தில் உள்ள அடிப்படை பல பொருள் தமிழ் சொற்களுக்கு மட்டுமே துல்லியமான சூழல் பகுப்பாய்வு உடனடியாகச் செயல்படும். களஞ்சியத்தில் இல்லாத புதிய சொற்களுக்கு "களஞ்சியத்தில் சேர்க்கப்படவில்லை" என்ற நேர்மையான தகவல் காட்டப்படும்.
2. உருபனியல் பகுப்பாய்வு (Morphological Stemming) அடிப்படை வேற்றுமை உருபுகள் மற்றும் சந்திகளை ஆதரிக்கிறது; மிகச் சிக்கலான அடுக்குச் சந்திகளுக்கு களஞ்சியத்தில் `target_form` பதிவு செய்யப்படுவது சிறந்தது.
3. செயற்கை நுண்ணறிவு மாதிரிகள் ஏதும் போலியாகப் பாசாங்கு செய்யப்படவில்லை; இது முற்றிலும் வெளிப்படையான, சரிபார்க்கப்பட்ட மொழியியல் தொடரமைப்பு விதிகளின் அடிப்படையில் இயங்குகிறது.
